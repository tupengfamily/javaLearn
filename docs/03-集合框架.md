# 第 8-9 章:字符串与集合框架 ⭐

> **集合是日常开发中使用频率最高的类。** 本章必须熟练掌握。

## 一、字符串(String)

`String` 是**不可变对象**(Immutable),任何修改都会创建新对象。

### 字符串常量池

JVM 为了节省内存,把相同字符串只存储一份。

```java
String s1 = "Hello";           // 常量池
String s2 = "Hello";           // 复用常量池中的对象
String s3 = new String("Hello"); // 堆中新对象
String s4 = s3.intern();       // 把字符串放入常量池

s1 == s2;  // true
s1 == s3;  // false
s1 == s4;  // true
```

**常用方法**:
- `length()`: 长度
- `trim()` / `strip()`: 去空白(`strip` 支持 Unicode)
- `toUpperCase()` / `toLowerCase()`: 大小写
- `contains()` / `startsWith()` / `endsWith()`: 判断
- `indexOf()` / `lastIndexOf()`: 查找位置
- `substring(begin, end)`: 截取 [begin, end)
- `replace()` / `replaceAll()`: 替换(后者支持正则)
- `split()`: 分割
- `format()`: 格式化
- `isEmpty()` / `isBlank()`: 空判断

### StringBuilder(可变字符串)

频繁拼接用 `StringBuilder`,性能更好。

```java
StringBuilder sb = new StringBuilder();
sb.append("Hello")
  .append(" ")
  .append("World");
String result = sb.toString();
```

## 二、集合框架总览

```
Collection (接口)
├── List (有序、可重复)
│   ├── ArrayList   ← 数组实现,查询快 O(1)
│   ├── LinkedList  ← 链表实现,增删快 O(1)
│   └── Vector      ← 古老,线程安全
└── Set (无序、不重复)
    ├── HashSet       ← 哈希表,O(1)
    ├── LinkedHashSet ← HashSet 子类,保持插入顺序
    └── TreeSet       ← 红黑树,有序,O(log n)

Map (键值对)
├── HashMap         ← 主流
├── LinkedHashMap   ← 保持插入顺序
├── TreeMap         ← Key 有序
└── Hashtable       ← 古老,线程安全
```

## 三、List 详解

### ArrayList(最常用)

```java
List<String> list = new ArrayList<>();
list.add("A");          // 添加
list.add(0, "B");       // 指定位置插入
list.get(0);            // 访问
list.set(0, "C");       // 修改
list.remove(0);         // 按下标删除
list.remove("C");       // 按内容删除
list.size();            // 大小
list.contains("A");     // 判断
```

**内部结构**: 数组,容量不足时自动扩容为 1.5 倍。

**性能**:
- 查询(get): O(1) - 数组按下标访问
- 增删(add/remove): O(n) - 需要移动元素

### LinkedList

- 内部是双向链表
- 增删快 O(1),查询慢 O(n)
- 可用作栈(`push`/`pop`)或队列(`offer`/`poll`)

### 遍历方式(4 种)

```java
// 1. 普通 for(可以增删)
for (int i = 0; i < list.size(); i++) {
    System.out.println(list.get(i));
}

// 2. 增强 for(只能读)
for (String s : list) {
    System.out.println(s);
}

// 3. Iterator(可以安全删除)
Iterator<String> it = list.iterator();
while (it.hasNext()) {
    String s = it.next();
    it.remove();  // 安全的删除方式
}

// 4. forEach + Lambda(Java 8+)
list.forEach(System.out::println);
```

## 四、Set 详解

### HashSet

- 基于 `HashMap` 实现,无序
- 通过 `hashCode()` 和 `equals()` 判断重复
- 允许一个 `null`

### LinkedHashSet

- `HashSet` 的子类,内部用链表维护插入顺序

### TreeSet

- 基于红黑树,元素有序(自然顺序或自定义)
- 元素必须实现 `Comparable`,或传入 `Comparator`

```java
Set<Integer> tree = new TreeSet<>();
tree.add(5); tree.add(1); tree.add(3);  // [1, 3, 5]

// 自定义排序
Set<String> byLength = new TreeSet<>(Comparator.comparingInt(String::length));
```

## 五、Map 详解

### HashMap(最常用)

```java
Map<String, Integer> map = new HashMap<>();
map.put("A", 1);           // 添加
map.get("A");               // 取值(不存在返回 null)
map.getOrDefault("B", 0);  // 带默认值
map.containsKey("A");      // 判断 Key
map.containsValue(1);      // 判断 Value
map.remove("A");           // 删除
map.size();                // 大小
```

**遍历 Map**:
```java
// 1. entrySet(最常用)
for (Map.Entry<String, Integer> entry : map.entrySet()) {
    System.out.println(entry.getKey() + " = " + entry.getValue());
}

// 2. keySet + get
for (String key : map.keySet()) {
    System.out.println(key + " = " + map.get(key));
}

// 3. values
for (Integer value : map.values()) { ... }

// 4. forEach + Lambda
map.forEach((k, v) -> System.out.println(k + " = " + v));
```

## 六、选择合适的集合

```
需要键值对?       → Map
  ├─ 顺序无所谓    → HashMap(默认)
  ├─ 保持插入顺序  → LinkedHashMap
  └─ Key 有序      → TreeMap

只是值的集合?     → Collection
  ├─ 可重复      → List
  │   ├─ 查询多    → ArrayList(默认)
  │   └─ 增删多    → LinkedList
  └─ 不重复      → Set
      ├─ 无序      → HashSet
      ├─ 插入顺序  → LinkedHashSet
      └─ 有序      → TreeSet
```

## 七、不可变集合(Java 9+)

```java
List<String> list = List.of("A", "B", "C");
Set<Integer> set = Set.of(1, 2, 3);
Map<String, Integer> map = Map.of("A", 1, "B", 2);
```

**不可变集合** 不可增删改,适合只读场景,线程安全。
