# 第 10 章:异常处理

> 程序运行中难免出错,Java 用异常机制优雅地处理错误。

## 一、什么是异常?

异常(Exception)是程序运行中发生的**不正常情况**,会中断程序的正常执行。

例如:
- 数组下标越界
- 除数为 0
- 文件不存在
- 网络中断

## 二、异常体系

```
Throwable
├── Error            (严重错误,程序无法处理,如 OOM)
└── Exception
    ├── IOException            (检查异常,必须处理)
    ├── SQLException
    └── RuntimeException       (运行时异常,不强制处理)
        ├── NullPointerException
        ├── ArrayIndexOutOfBoundsException
        ├── ArithmeticException
        └── ClassCastException
```

**两大类:**
- **检查异常(Checked)**: 编译器强制要求处理,如 `IOException`
- **运行时异常(Unchecked)**: 继承 `RuntimeException`,编译器不强制,如 `NullPointerException`

## 三、异常处理关键字

### 1. try-catch-finally

```java
try {
    // 可能出错的代码
    int result = 10 / 0;
} catch (ArithmeticException e) {
    // 捕获特定异常
    System.out.println("算术异常: " + e.getMessage());
} catch (Exception e) {
    // 捕获更宽泛的异常(必须排在子类之后)
    System.out.println("其他异常");
} finally {
    // 无论是否异常都会执行
    System.out.println("清理资源");
}
```

### 2. throw

在方法**内部**主动抛出异常。

```java
if (age < 0) {
    throw new IllegalArgumentException("年龄不能为负");
}
```

### 3. throws

在方法**声明**上声明可能抛出的异常,把异常抛给调用者处理。

```java
public void readFile(String path) throws IOException {
    FileReader reader = new FileReader(path);  // 可能抛 IOException
}
```

**throw vs throws**:
- `throw`: 动词,抛出异常对象,用在方法体
- `throws`: 名词,声明异常类型,用在方法签名

## 四、try-with-resources(Java 7+)

自动关闭实现了 `AutoCloseable` 接口的资源。

```java
// 传统方式: 手动关闭
FileReader reader = null;
try {
    reader = new FileReader("test.txt");
    // ...
} catch (IOException e) {
    // ...
} finally {
    if (reader != null) {
        try { reader.close(); } catch (IOException e) { }
    }
}

// try-with-resources: 自动关闭
try (FileReader reader = new FileReader("test.txt")) {
    // ...
} catch (IOException e) {
    // ...
}
// reader 在 try 结束时自动关闭
```

**可同时管理多个资源**:
```java
try (
    var in = Files.newInputStream(src);
    var out = Files.newOutputStream(dst)
) {
    // ...
}
```

## 五、自定义异常

```java
// 检查异常
public class BusinessException extends Exception {
    private final String errorCode;

    public BusinessException(String errorCode, String message) {
        super(message);
        this.errorCode = errorCode;
    }
}

// 运行时异常
public class IllegalAgeException extends RuntimeException {
    public IllegalAgeException(String message) {
        super(message);
    }
}
```

**使用**:
```java
if (amount < 0) {
    throw new BusinessException("AMT_001", "金额不能为负");
}
```

## 六、常用异常

| 异常 | 场景 |
|------|------|
| `NullPointerException` | 调用 null 对象的方法 |
| `ArrayIndexOutOfBoundsException` | 数组下标越界 |
| `ArithmeticException` | 算术异常(如除 0) |
| `NumberFormatException` | 数字格式错误 |
| `ClassCastException` | 类型转换错误 |
| `IllegalArgumentException` | 参数不合法 |
| `IOException` | IO 错误 |
| `FileNotFoundException` | 文件不存在 |

## 七、异常处理最佳实践

✅ **应该做的:**
- 捕获具体的异常,而不是所有 `Exception`
- 记录异常(`e.printStackTrace()` 或日志)
- 资源用 try-with-resources
- 抛出业务异常时,提供有意义的消息
- 自定义异常继承 `Exception` 或 `RuntimeException`

❌ **不应该做的:**
- 捕获异常后什么都不做(`catch (Exception e) {}`)
- 用异常控制业务流程(性能差)
- 捕获 `Throwable` 或 `Error`
- 在 `finally` 中 `return`(会吞掉异常)
