# 第 7 章:面向对象(OOP) ⭐

> **本章是 Java 最重要的章节。** Java 是纯粹的面向对象语言,所有代码都是基于类的。

## 什么是面向对象?

面向对象(Object-Oriented Programming, OOP)是一种**程序设计思想**,把程序看作由许多相互协作的对象组成。

**核心概念:**
- **类(Class)**: 对象的模板/图纸
- **对象(Object)**: 类的实例,具体的事物
- **属性(Field)**: 对象的数据
- **方法(Method)**: 对象的行为

**类与对象的关系**: 类是抽象的,对象是具体的。
例如:`Animal` 是类,`旺财(具体的一只狗)` 是对象。

## 一、封装(Encapsulation)

**目的**: 隐藏内部实现细节,只暴露必要的接口。

```java
public class Animal {
    private String name;  // private: 仅本类可见
    private int age;

    // 提供 getter/setter 访问
    public String getName() { return name; }
    public void setName(String name) { this.name = name; }

    public int getAge() { return age; }
    public void setAge(int age) {
        if (age < 0) {  // 在 setter 中加入校验
            System.out.println("年龄不能为负");
            return;
        }
        this.age = age;
    }
}
```

**访问修饰符:**

| 修饰符 | 本类 | 同包 | 子类 | 其他 |
|--------|------|------|------|------|
| `private` | ✓ | ✗ | ✗ | ✗ |
| 默认(无) | ✓ | ✓ | ✗ | ✗ |
| `protected` | ✓ | ✓ | ✓ | ✗ |
| `public` | ✓ | ✓ | ✓ | ✓ |

## 二、继承(Inheritance)

**目的**: 子类复用父类的代码,体现"is-a"关系。

```java
public class Animal {
    public String name;
    public void eat() { System.out.println(name + " 在吃"); }
}

public class Dog extends Animal {  // extends 关键字
    public String breed;
    public void fetch() { System.out.println(name + " 在捡球"); }
}
```

**特点:**
- Java 是**单继承**(一个类只能有一个直接父类)
- 子类继承父类**非 private** 的字段和方法
- 构造方法**不会**被继承
- 用 `super` 关键字访问父类

### 方法重写(Override)

子类改写父类的方法:

```java
@Override  // 注解,编译器会检查是否真的重写了父类方法
public void makeSound() {
    System.out.println("汪汪汪");  // 替换父类的实现
}
```

**重写规则:**
1. 方法名和参数列表必须相同
2. 返回类型相同或是其子类
3. 访问修饰符不能更严格
4. 不能抛出比父类更多的异常

### super 关键字

```java
public Dog(String name, int age, String breed) {
    super(name, age);  // 调用父类构造方法,必须放在第一行
    this.breed = breed;
}

public void showParent() {
    super.eat();  // 调用父类方法
}
```

## 三、多态(Polymorphism)

**多态**: 同一行为具有不同表现形态。

```java
Animal animal1 = new Dog("旺财", 4, "柴犬");
Animal animal2 = new Cat("小花", 3, "橘色");

animal1.makeSound();  // 汪汪汪
animal2.makeSound();  // 喵喵喵
```

**多态的三个条件:**
1. ✅ 继承(或实现接口)
2. ✅ 方法重写
3. ✅ 父类引用指向子类对象

**多态的应用:**
- 形参用父类类型
- 返回值用父类类型
- 数组/集合用父类类型

**`instanceof`**: 判断对象的实际类型。

```java
if (animal instanceof Dog dog) {  // Java 16+ 模式匹配
    dog.fetch();
}
```

## 四、抽象类(Abstract Class)

**定义模板,不能实例化:**

```java
public abstract class Shape {
    protected String color;

    public abstract double area();   // 抽象方法: 没有实现
    public abstract double perimeter();

    public void display() {  // 具体方法
        System.out.println("面积: " + area());
    }
}

public class Circle extends Shape {
    private double radius;

    @Override
    public double area() { return Math.PI * radius * radius; }

    @Override
    public double perimeter() { return 2 * Math.PI * radius; }
}
```

**特点:**
- 不能 `new Shape()`(抽象类不能实例化)
- 可以包含抽象方法和具体方法
- 子类必须实现**所有**抽象方法,否则子类也得是抽象类

## 五、接口(Interface)

**定义行为契约:**

```java
public interface Flyable {
    int MAX_HEIGHT = 10000;       // 常量(默认 public static final)
    void fly();                  // 抽象方法(默认 public abstract)

    default void land() {        // Java 8+: 默认方法
        System.out.println("安全着陆");
    }

    static void about() {        // Java 8+: 静态方法
        System.out.println("可飞行接口");
    }
}
```

**接口 vs 抽象类:**

| 特性 | 接口 | 抽象类 |
|------|------|--------|
| 实现方式 | `implements` | `extends` |
| 多继承 | ✅ 一个类可实现多个接口 | ❌ 单继承 |
| 字段 | 仅常量 | 任意字段 |
| 方法 | 默认 public 抽象 + default/static | 任意 |
| 构造方法 | ❌ 没有 | ✅ 有 |

**多接口实现:**

```java
public class Duck extends Animal implements Flyable, Swimmable {
    @Override public void fly() { ... }
    @Override public void swim() { ... }
}
```
