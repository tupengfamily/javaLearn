# 第 1-6 章:Java 基础语法

> 本文档面向 Java 零基础学习者,讲解最基础的语法概念。

## 第一个程序

每个 Java 程序都从 `main` 方法开始执行:

```java
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```

**关键点:**
- `public class`: 声明一个公共类,**类名必须与文件名相同**
- `public static void main(String[] args)`: 程序入口
- `System.out.println()`: 向控制台输出

## 数据类型

Java 有 8 种基本数据类型:

| 类型 | 大小 | 默认值 | 取值范围 |
|------|------|--------|----------|
| `byte` | 1 字节 | 0 | -128 ~ 127 |
| `short` | 2 字节 | 0 | -32768 ~ 32767 |
| `int` | 4 字节 | 0 | ±21 亿 |
| `long` | 8 字节 | 0L | 巨大(需加 L 后缀) |
| `float` | 4 字节 | 0.0f | 小数(需加 f 后缀) |
| `double` | 8 字节 | 0.0d | 双精度小数(默认) |
| `char` | 2 字节 | '\u0000' | 单个字符(单引号) |
| `boolean` | 1 字节 | false | true / false |

**引用类型**:`String`(字符串)、数组、对象等。

## 变量与常量

```java
int age = 18;          // 变量
final double PI = 3.14; // 常量(final 修饰,不可修改)
```

## 类型转换

- **自动转换**: 小类型转大类型,自动完成
- **强制转换**: 大类型转小类型,需显式声明,可能丢失精度

```java
int a = 10;
double b = a;        // 自动
int c = (int) 3.14;  // 强制,c = 3
```

## 运算符

- **算术**: `+`, `-`, `*`, `/`, `%`, `++`, `--`
- **比较**: `==`, `!=`, `>`, `<`, `>=`, `<=` (返回 boolean)
- **逻辑**: `&&`(短路与), `||`(短路或), `!`(非)
- **三元**: `条件 ? 值1 : 值2`
- **位运算**: `&`, `|`, `^`, `<<`, `>>`, `>>>`

## 控制流程

### 分支

```java
if (条件) {
    // ...
} else if (条件) {
    // ...
} else {
    // ...
}

// Java 14+ 新版 switch
String result = switch (day) {
    case "MON", "TUE" -> "工作日";
    case "SAT", "SUN" -> "周末";
    default -> "未知";
};
```

### 循环

```java
// for
for (int i = 0; i < 10; i++) { }

// foreach
for (String s : list) { }

// while
while (条件) { }

// do-while(至少执行一次)
do { } while (条件);
```

### 跳转

- `break`: 跳出当前循环
- `continue`: 跳过本次循环
- `return`: 结束方法

## 数组

```java
int[] arr = new int[5];
int[] arr2 = {1, 2, 3, 4, 5};

System.out.println(arr2.length); // 注意 length 是属性,不是方法
arr2[0] = 99; // 通过下标访问
```

**常见错误**:
- `ArrayIndexOutOfBoundsException`: 下标越界
- `NullPointerException`: 空指针

## 方法

```java
修饰符 返回类型 方法名(参数) {
    // 方法体
    return 返回值;
}
```

**方法重载**: 同名不同参数(数量、类型、顺序)。

**参数传递**:
- 基本类型: 值传递,方法内修改不影响外部
- 引用类型: 传地址,方法内修改会影响外部

## 字符串(String)

`String` 是不可变对象,任何修改都创建新对象。

```java
String s = "Hello";
String s2 = new String("Hello");
String s3 = s + " World"; // 拼接,实际创建新对象
```

**常用方法**: `length()`, `substring()`, `indexOf()`, `replace()`, `split()`, `trim()`, `equals()`, `startsWith()` ...

**频繁拼接用 StringBuilder**:
```java
StringBuilder sb = new StringBuilder();
sb.append("Hello").append(" ").append("World");
String result = sb.toString();
```
